Which way is for you?

Both work the same on the night: same DJ list, same QR code and poster, and songs go straight into EZTiger.

You'll need

  • A free Cloudflare account: dash.cloudflare.com/sign-up. Cloudflare runs your request page.
  • A free GitHub account: github.com/signup. Cloudflare keeps your copy of the request page's program there and uses it to build your page.
  • EZTiger Pro on Windows, build BUILD or later, with your songs added.
  • A computer with internet. A phone works for the accounts, but the setup page is easier on a laptop.
Make up your DJ code first. It's the password for your DJ list: 20 or more letters and numbers, no spaces, for example Tiger7Karaoke2Night9Dave4 (don't use this one). Write it down; you'll type it once in step 5.

Set it up

Use the same web browser for every step, so you stay signed in.

Make your two free accounts

Sign up at github.com/signup, then at dash.cloudflare.com/sign-up. Confirm each one from the email it sends you.

Open the Deploy link

Type this address into your browser (or click it in the PDF):
DEPLOY_URL

Connect GitHub

Cloudflare asks to connect to GitHub so it can make your copy. Choose your GitHub account and allow it.

Name it

On Cloudflare's setup page, the project is called eztiger-requests. Change the name if you like (letters, numbers and dashes): it becomes part of your web address. Leave the storage names as they are.

Add your DJ code

Where the page asks for DJ_KEY, type the DJ code you made up. Then press Create and deploy (or Deploy) and wait a minute or two until it says it's live.

Note your two links

Cloudflare shows your web address, like https://eztiger-requests.dave.workers.dev. Your DJ link is that address with /dj?key= and your DJ code on the end:
https://eztiger-requests.dave.workers.dev/dj?key=YourDJCode
Open it: you should see an empty DJ list. Save it somewhere safe.

Connect EZTiger

In EZTiger, go to ☰ Menu → Song requests, paste your DJ link into the box and press Connect (it says ✓ Connected). Then ☰ Menu → Start song requests puts your songs on your page and opens your DJ list.

From then on

Everything else is the same as EZTiger's service: see the First-time setup guide, pages 2 and 3, for the night itself, posters, your own taskbar button, and venues with no signal.

  • Each night: laptop on the internet, open EZTiger, ☰ Menu → Start song requests.
  • Added songs: Start song requests again. Your address and QR code never change.
  • Your free plan: Cloudflare's free plan allows 100,000 visits a day, far more than one venue's singers use. You won't be charged unless you choose a paid plan yourself.

If something's not right

You seeTry this
"This request list isn't set up yet: the owner needs to add the DJ_KEY secret"The DJ code didn't get saved. In Cloudflare: Workers & Pages → eztiger-requests → Settings → Variables and Secrets → Add, type Secret, name DJ_KEY, value: your DJ code. Save (Deploy).
"The DJ list needs the DJ link"The code on the end of your DJ link doesn't match DJ_KEY. Check for typos and spaces, or set DJ_KEY again as above.
Your web address doesn't open yetA brand-new address can take a few minutes to start working. Try again shortly.
"Can't reach the online request list" in EZTigerThe laptop isn't on the internet: join the venue Wi-Fi or your phone's hotspot.
Phones say "The song list isn't up yet"Press ☰ Menu → Start song requests in EZTiger.
Changed your mind?Disconnect anytime: in ☰ Menu → Song requests press Turn off, or use Get my online request page for EZTiger's service. To remove your copy, delete the eztiger-requests Worker in Cloudflare.
Your data. Only song titles and artists, the names singers type and their notes go online, onto your own Cloudflare account. Your song files stay on your laptop.
